# 天天赚钱: 自动创新助手 — 产品介绍

> 面向使用者的入门说明。想看逐步操作细节，请阅读 [使用说明](./USER_GUIDE.md)。
>
> 本文以插件 1.9.12 的功能为准；界面与能力以你实际安装的版本为准。

## 30 秒了解

**天天赚钱: 自动创新助手** 是一个 Chrome 扩展。它把「你在网页上看到的问题」直接变成「云端智能体可以执行的任务」：

1. 在网页上点选有问题的地方（或者直接让它通读整页）；
2. 插件自动带上元素、选择器、页面链接、可见文案等你本来要复制粘贴的信息；
3. 你补一句「希望改成什么样」，就能在侧栏 / DevTools 里创建任务，或把建议直接发给 Cursor / Claude / Codex。

它不替你做决定，也不会背着你自动改线上代码——它负责把需求表达清楚、把任务送进正确的项目；执行与交付仍由平台上的智能体和你确认。

## 它解决什么问题

| 以前的麻烦 | 用插件之后 |
|---|---|
| 截图、复制文案、手写「这个按钮太丑」，再切到平台找项目建任务 | 页内点选元素，元素标识、页面链接、调整期望自动写进任务描述 |
| 只感觉「这页不好看」，却说不出具体改哪里 | `Alt+Z` 生成整页优化建议；`Alt+Shift+Z` 只针对点选区域生成 |
| 页面内容不错，但搜索收录 / 排名不理想 | 选「系统默认·SEO」生成 On-Page SEO 方案：标题、关键词、图片 alt、内链、Schema 等 |
| 线上出现 5xx，要一个个记下来再建任务 | 批量错误捕获，按状态码收集，一次批量建任务 |
| 在编辑器和平台之间反复复制粘贴 | 转发目标选 Cursor / Claude / Codex，点「发送到 …」即深链预填 |

## 适合谁

- **产品经理 / 运营**：把网页体验问题变成研发可执行的任务，不用写技术描述。
- **测试 / 研发**：复现请求直接建任务；线上 5xx 批量归集。
- **站长 / 独立开发者**：快速获得整页或局部的优化建议。
- **团队管理者**：用工作空间、项目、自动运行、硬件库存把「提需求」和「跑任务」接起来。

## 核心能力

### 1. 指哪改哪：`Alt+X` 选元素

- 在任意网页按 `Alt+X` 进入选元素模式，鼠标悬停时目标元素出现高亮框。
- **单击**选中单个元素 → 填写「调整期望」；按 `Esc` 或再按一次快捷键可取消。
- **多选不关联元素**：按住 `⌘/Ctrl` 再点击可累加（再点取消），按 `Enter` 确认；`Esc` 先清空多选，再按退出。
- 支持 Shadow DOM、同源 / 跨域 iframe；选中原生控件（video / audio 等）时，浏览器不允许穿透内部，插件会选中宿主元素并在描述中注明。
- 可勾选「附带元素截图」：截取选中区域后临时上传，任务描述里写入带有效期的 https 链接；多选时截取全部选中元素的包围盒并集。
- 确认后，元素标识、调整期望、页面链接会自动追加到任务描述；也可以选择把这段内容发给 Cursor / Claude / Codex。

### 2. 页面优化建议：`Alt+Z` / `Alt+Shift+Z`

- **`Alt+Z`**：采集当前页可见文案与 DOM 大纲，生成整页优化建议。
- **`Alt+Shift+Z`**：先点选页面元素（或多选），再只针对这个范围生成建议。
- 登录后由平台后端生成，工作空间决定合并哪些自定义提示词；未登录时走匿名每日试用。
- 建议以**锚定悬浮卡**展示：悬停卡片会高亮对应的页面区域；勾选可在页面上做临时预览，取消勾选立即还原。
- 底栏「拷贝并全部填入 / 拷贝并逐条填入」会把建议写入侧栏的任务描述——**只填入，不自动创建任务**，仍需你检查和提交。
- 如果转发目标选了 Cursor / Claude / Codex，生成后不会自动发送；点底栏「发送到 …」才会经官方深链打开编辑器并预填。

### 3. 智能体优化方向与 SEO 方案生成

页面优化建议不是一套固定规则，而是由**平台提示词目录**决定优化方向。登录后目录会合并所选工作空间的自定义提示词；未登录时使用公开目录，并走平台默认的匿名试用。

| 优化方向 | 适合解决的问题 |
|---|---|
| 系统默认·SEO | On-Page SEO：title / H1、meta description、标题层级、关键词布局、图片 alt、内链锚文本、Schema、抓取可达性 |
| 系统默认·SEO 深度审计（jev-seo） | 平台先做确定性审计，再按审计发现改写正文；下拉中带「· 审计」标记 |
| 系统默认·转化 | 在 SEO 友好前提下优化价值主张、CTA、社会证明、信任信号与表单阻力 |
| 系统默认·无障碍 | WCAG 2.1 AA：键盘操作、对比度、ARIA、表单、动效与缩放 |
| 系统默认·性能 | LCP、CLS、INP、资源加载、主线程阻塞与 CSS / JS 体积 |
| 系统默认自动创新 | 视觉层级、信息架构、交互微创新与移动端体验 |
| 工作空间自定义 | 在 SaaS「自动创新提示词管理」维护，合并进该工作空间的目录 |

> 目录由服务端下发，插件只展示标题、方向与「审计」标记；提示词正文不进入插件。选中的提示词随生成请求下发，`Alt+Z` 与 `Alt+Shift+Z` 共用同一份。

#### SEO 优化方案怎么生成

1. 在侧栏「设置」选好工作空间，再在「网页优化」顶部选择「系统默认·SEO」；需要深度审计时选带「· 审计」标记的 SEO 深度审计。
2. 打开目标页面，按 `Alt+Z` 生成整页方案；或按 `Alt+Shift+Z` 先点选区域，只优化该区域。
3. 普通 SEO 提示词的建议内容通常包含：**SEO 现状诊断**（问题 + 风险等级）、**P0/P1/P2 优先级**、**多套方案**（如最小改动安全版 / 语义增强版 / 内容拓展实验版）、推荐方案的文案与结构、**工程化改动清单**、HTML / JSON-LD 片段、验证方法与风险提示。深度审计模式则以平台审计发现与改写后的正文为主。具体字段随提示词版本略有差异。
4. 悬停卡片可对照页面区域；勾选做临时预览，确认后「拷贝并全部填入」写入任务描述，或「发送到 …」转发到 Cursor / Claude / Codex。
5. 到侧栏「创建任务」或 DevTools 面板提交任务，交给智能体实施。插件只生成方案，**不会自动改线上页面**。

> SEO 方案遵循白帽约束：不堆砌关键词、不隐藏文字、不编造客户 / 数据 / 资质；修改标题、Schema 或内链可能带来短期排名波动。建议按方案里的验证方法与 A/B 测试步骤小步上线。**SEO 建议不等于排名保证**，最终效果取决于页面真实内容、站点质量与搜索引擎规则。

> 生成建议时插件采集当前页的可见文本、DOM 大纲与 URL / 标题；登录墙、反爬或纯客户端渲染的页面可能采集不到，可刷新页面、改用区域点选，或先让目标内容可见。

### 4. 侧栏快速创建任务

- 点击工具栏图标展开 / 收起侧边栏。页签：**网页优化 / 创建任务 / 设置 / 边缘算力**。
- 建任务字段与网页端工作面板对齐：工作空间、项目（单选）、标题、描述、优先级、进度列、交付物、镜像、智能体资源配置、负责人、协作人、截止日期、分支策略等。
- 同名工作空间来自不同公司时，选项会显示「名称 · 公司名」，避免选错。
- **自动运行**需要同时满足：项目允许自动运行 + 已选择已安装镜像 + 已设置 Git 提交身份 + 项目运行硬件有库存。工作空间启用自动调度时，还可勾选「加入自动调度队列」。
- 创建成功后页面右下角会提示任务 ID，点击可在新标签页打开任务详情。

### 5. DevTools：单请求与批量错误

- 按 `F12` → 切换到「天天赚钱: 自动创新助手」面板。
- **单请求创建**：请求列表支持搜索，按方法 / 状态 / 类型筛选，点击列头排序；选中一条后，请求头 / 请求体 / 响应头 / 响应体会自动写入任务描述。支持 Canceled（客户端中止）请求。
- **批量错误捕获**：启用后按状态码收集请求；角标示数、错误列表、批量建任务**只计 HTTP 5xx**（4xx、Canceled、2xx / 3xx 可以预览，但不计入示数、不进入批量建任务）。
- **错误列表 / 历史记录**：查看已捕获的错误与创建历史，失败任务可重试。

### 6.（可选）本机模型出售

- 如果你有一台支持 Chrome 内置模型（Prompt API）的电脑，可以把本机算力作为「边缘算力」出售给平台：平台把请求转到你的浏览器，由本机模型推理。
- 使用前先在账号中心「本机模型出售」创建出售项目，再在侧栏「边缘算力」选择项目并注册本机。插件会主动连接平台保活，**无需公网 IP**。
- 能力取决于设备与 Chrome 版本；中文语言包不可用时，插件会自动改用英语模型包探测与下载。
- 插件指纹按浏览器特征生成；清空扩展数据或更换浏览器 / 用户配置会被平台视为新节点，旧节点可在列表中取消注册。

## 5 分钟上手

### 第 1 步：安装

1. 从 [GitHub Releases](https://github.com/task2money/taskChromePlugin/releases)（或 [Gitee Releases](https://gitee.com/ljy-ruandao/task-chrome-plugin/releases)）下载最新版本，文件名形如 `task-chrome-plugin-v<版本>.zip`。
2. 解压到一个固定目录（以后更新也覆盖这里）。
3. 打开 `chrome://extensions/`，右上角开启「开发者模式」。
4. 点「加载已解压的扩展程序」，选择解压后的目录。
5. 也可以直接从源码目录加载：选择 `taskChromePlugin/` 目录。

> 以开发者模式加载时，侧栏「设置」和 DevTools 面板顶栏会标为 **Beta**，并对照 GitHub Release 检查是否最新。双击版本号可以立即重新检测。

### 第 2 步：登录

1. 点击工具栏的扩展图标展开侧边栏（默认进入「设置」），点顶栏「登录」。
2. 确认服务器地址（默认 `https://daydaymoney.com`，可修改）。
3. 点「OAuth 登录」，在打开的网页中完成授权（OAuth2 + PKCE）。
4. 登录成功后，工作空间列表会自动加载。

> 插件登录和网页登录是**两套会话**。如果网页换了账号，插件也要用同一账号重新登录。

### 第 3 步：选择工作空间

在侧边栏「设置」里选择「自动创新智能体」的工作空间。它决定 `Alt+Z` 合并哪些自定义提示词，也会影响建议落到的默认项目。

### 第 4 步：开始使用

- **想指出问题**：按 `Alt+X` 点选元素 → 填写调整期望 → 选择转发目标。
- **想要建议**：在「网页优化」顶部选提示词（如「系统默认·SEO」）→ 按 `Alt+Z`（整页）或 `Alt+Shift+Z`（先选区）→ 勾选建议 → 填入任务描述。
- **想排查请求**：按 `F12` 打开 DevTools → 天天赚钱: 自动创新助手 → 单请求创建 / 批量错误捕获。
- **创建任务**：统一在侧栏「创建任务」或 DevTools 面板完成；建议填入后仍需你手动提交。

## 数据与隐私

### 只保存在本机

- 登录令牌、服务器地址；
- 工作空间 / 项目选择、快捷键、转发目标、内容前缀；
- 请求捕获记录（最多 500 条）与任务历史；
- 本机模型相关的注册缓存与插件指纹。

### 会发送到你配置的平台服务器

- 登录认证信息；
- 创建任务时：任务字段，以及你选中的请求 / 页面信息；
- 使用 `Alt+Z` / `Alt+Shift+Z` 时：当前页标题、URL、可见文本、DOM 大纲（过长会截断）；
- 勾选「附带元素截图」时：裁剪后的截图（临时上传，返回带有效期的链接）；
- 未登录的匿名试用：按安装指纹、IP 与每日额度在服务端记账。

### 插件不会

- 申请 `cookies` 权限，不读取浏览器 Cookie；
- 维护你的浏览历史；网络请求捕获只用于请求面板与批量错误捕获；
- 内置第三方统计或广告 SDK；
- 在你未点击「发送到 …」时，把内容发给 Cursor / Claude / Codex。

> 提交任务或截图前，请自行确认内容中不含口令、密钥等敏感信息。卸载扩展或清空扩展数据会删除本机保存的内容。

## 安装、更新与版本

- **系统要求**：桌面版 Chrome（Manifest V3）。可选的「本机模型」能力还要求设备与 Chrome 版本支持内置 Prompt API。
- **下载**：[GitHub Releases](https://github.com/task2money/taskChromePlugin/releases) / [Gitee Releases](https://gitee.com/ljy-ruandao/task-chrome-plugin/releases)。
- **更新**：下载新版本并解压覆盖原目录 → 在 `chrome://extensions/` 点该扩展的「重新加载」→ 已打开的页面刷新一次。
- **版本检查**：侧栏「设置」和 DevTools 面板顶栏显示当前版本；开发者模式加载会标 Beta；双击版本号可立即重新检查（默认有一小时缓存）。
- **源码安装 / 开发**：见 [README](../README.md)。

## 常见问题

**Q1：按 `Alt+X` / `Alt+Z` 没反应？**
先确认扩展已启用；到 `chrome://extensions/shortcuts` 检查键位是否被其他扩展占用。插件还有页内按键兜底；若仍无效，重载扩展后刷新页面再试。

**Q2：提示「插件脚本还没进入当前网页」或「采集不到当前网页」？**
以开发者模式重载扩展后，重载前已打开的页面不会自动注入脚本，刷新该页一次即可。

**Q3：工作空间报「您不是该公司的成员」？**
插件登录与网页登录是两套会话。请在侧栏「设置」里用与网页相同的账号重新登录。

**Q4：「是否自动运行」勾不上？**
需同时满足：项目允许自动运行、已选择已安装镜像、已设置 Git 提交身份。工作空间启用自动调度时，还可以选择加入队列。

**Q5：提示没有硬件库存？**
该项目当前的运行硬件没有可用库存。按提示打开项目详情页更换硬件后再试。

**Q6：生成建议失败，提示里带 `traceId`？**
把完整错误文案（含 `traceId`）发给平台支持，或在 Grafana / Loki 按 `trace_id` 排查。客户端轮询上限约 75 秒，可点「重试」。

**Q7：本机模型一直不可用，或中文包报不可用？**
先确认 Chrome 版本与设备支持内置模型；插件在中文语言包不可用时会自动改用英语包。若仍失败，可在 `chrome://on-device-internals` 排查（高级排障页，谨慎修改参数）。

**Q8：为什么节点列表里多了几条？**
插件指纹按浏览器特征生成；清空扩展数据或换浏览器 / 用户配置会被视为新节点。不再使用的节点可在列表中取消注册。

**Q9：SEO 优化方案能保证排名吗？**
不能。插件生成的是 On-Page 优化建议与可执行的改动清单，不承诺排名；最终效果取决于页面真实内容、站点质量、竞争程度与搜索引擎规则。建议按方案中的验证方法小步上线，并用 A/B 测试或站长平台观察收录与排名变化。
