# 隐私政策 — 祝你天天赚钱: 自动创新助手

> English version: [Privacy Policy](./PRIVACY.en.md)
>
> 适用范围：Chrome 扩展「祝你天天赚钱: 自动创新助手」（DayDayMoney: Auto Innovate）。
> 生效日期：2026-11-14；本政策随扩展版本更新，最新版本以仓库本文件为准。

本政策说明扩展会读取哪些数据、用在哪里、保存多久，以及你可以如何控制。
它只描述扩展自身的行为；你连接的平台服务器（默认 `https://daydaymoney.com`，可在登录界面修改）
对账号与任务数据的处理，以该平台的服务条款与隐私政策为准。

## 1. 权限与用途

扩展在 `manifest.json` 中声明的权限与对应用途如下（与声明一一对应）：

| 权限 | 用途 |
|---|---|
| `storage` | 在本机保存登录令牌、服务器地址、工作空间 / 项目选择、快捷键、转发目标、内容前缀、建议缓存等设置 |
| `alarms` | 定时刷新角标、建议队列与「本机模型」保活心跳；不使用后台常驻轮询页面 |
| `webRequest` | 填充 DevTools 单请求面板、按状态码批量捕获 5xx 错误；仅在你打开对应功能时记录 |
| `tabs` | 读取当前标签页的 URL / 标题以关联页面上下文，并把任务或建议投递到正确的标签页 |
| `webNavigation` | 页面导航 / 刷新完成事件，用于刷新待办入口与页面上下文 |
| `sidePanel` | 提供侧边栏界面（网页优化 / 创建任务 / 设置 / 边缘算力） |
| `downloads` | 检查到 Beta 新版本时下载 zip，并在完成后打开 `chrome://extensions/` 供你手动加载 |
| `clipboardWrite` | 「拷贝并全部填入 / 拷贝并逐条填入」把建议写入剪贴板 |
| 主机权限 `<all_urls>` | 在任意网页注入内容脚本，实现 `Alt+X` 选元素、`Alt+Z` / `Alt+Shift+Z` 生成建议、页内预览与建议卡渲染 |

扩展**不申请** `cookies`、`history`、`bookmarks`、`identity` 等权限，不读取浏览器 Cookie，
也不维护你的浏览历史。

## 2. 数据分类

### 2.1 仅保存在本机（浏览器扩展存储）

- 登录令牌与服务器地址（退出登录只清令牌，不重置地址）；
- 工作空间 / 项目选择、快捷键、转发目标、内容前缀、界面语言等设置；
- 建议缓存（用于离线展示同一网址的历史建议）；
- 请求捕获记录（最多 500 条）与任务创建历史；
- 「本机模型」注册缓存与插件指纹；
- 「定位源码（本机）」开关状态；定位结果不落盘，刷新即失效。

### 2.2 会发送到你配置的平台服务器

- 登录与 OAuth2 + PKCE 认证信息；
- 创建任务时：任务字段（标题、描述、优先级、项目、工作空间等）与你选中的请求 / 页面信息；
- 使用 `Alt+Z` / `Alt+Shift+Z` 时：当前页标题、URL、可见文本、DOM 大纲（过长会截断）、所选提示词 id；
- 勾选「附带元素截图」时：裁剪后的截图（临时上传，返回带有效期的链接，写入任务描述）；
- 未登录的匿名试用：服务端按安装指纹、IP 与每日额度记账；
- 使用「本机模型出售」时：设备注册信息与出站保活心跳；
- 勾选「附带源码定位」时：仅 `源文件:行`（不含源码正文）随任务描述或 IDE 深链发送。

### 2.3 扩展不会收集

- 不内置第三方统计或广告 SDK，不向第三方出售或共享数据；
- 不在你未点击「发送到 …」时把内容发给 Cursor / Claude / Codex（该动作经官方深链打开编辑器并预填，需你主动触发）；
- 不采集与网页优化、任务创建无关的页面内容。

### 2.4 源码定位（本机）

- 仅在 `Alt+X` 点「定位源码」或开启 `Alt+Z` 底栏开关时运行；
- 只读取当前页已加载的公开脚本 / CSS 及页面自己声明的 source map；请求统一不带 Cookie（`credentials: omit`），并拒绝 loopback / 私网 / 链路本地 / 云元数据地址；
- 不读取任何表单 `value`；源码正文不上传、不写入扩展存储、不写日志；
- 只有你勾选「附带源码定位」后，`源文件:行` 才随任务描述或 IDE 深链发送。

## 3. 保留期

| 数据 | 保留期 |
|---|---|
| 登录令牌 | 直到你退出登录、卸载扩展或清空扩展数据 |
| 设置与建议缓存 | 直到你修改、清空扩展数据或卸载 |
| 请求捕获记录（≤500 条）与任务历史 | 滚动保留最近 500 条，可在面板内清除；卸载即删除 |
| 元素截图 | 上传后以带有效期（TTL）的链接提供，到期后由服务端清理；具体 TTL 由平台配置 |
| 平台侧任务与账号数据 | 由所连接平台的服务条款与隐私政策规定 |
| 匿名试用记账 | 服务端按日额度记账，用于限量与防滥用 |

## 4. 你的控制

- **随时退出 / 清除**：侧栏「设置」退出登录只清令牌；清空扩展数据或卸载扩展会删除全部本机数据。
- **截图可选**：不勾选「附带元素截图」就不会上传任何截图。
- **转发手动触发**：转发到 Cursor / Claude / Codex 只在你点击「发送到 …」时发生。
- **请求捕获可关**：DevTools 面板的「跟踪请求」可随时关闭，并可清除已捕获记录。
- **节点注销**：「本机模型出售」的已注册节点可在列表中取消注册，停止保活。
- **敏感内容提示**：提交任务或截图前，请自行确认不含口令、密钥等敏感信息。

继续使用更新后的扩展即表示你接受更新后的政策。
