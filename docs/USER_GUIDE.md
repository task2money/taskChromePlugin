# Task Chrome Plugin — 使用说明

**版本对齐**：`lib/user-guide.js`（UI 渲染 SSOT）  
**维护规则**：见目录 [`../ai.md`](../ai.md) — **新增/变更用户可见功能时必须同步更新本文与 `user-guide.js`**。

---

## 插件能做什么

- 从 DevTools Network / 页内浮窗捕获请求或页面元素，快速创建对齐工作面板的任务。
- 主要入口：① 扩展弹窗登录 ② 页内悬浮球快速建任务 ③ DevTools「TaskPlugin」面板（单请求 / 批量错误）。

## 登录与服务器

1. 点击扩展图标 → 填写服务器地址、账号（用户名或邮箱）、访问令牌（task2app「个人资料 → 访问令牌」，以 `at_` 开头）。
2. 服务器地址会自动记住；退出登录只清除令牌，不重置地址。
3. 未登录时浮窗会显示「未登录」；请先在弹窗完成登录后再创建任务。

## 页内浮窗 — 快速创建任务

1. 打开任意网页 → 点击右下角悬浮球「+」打开浮窗（可在弹窗或浮窗内关闭「显示悬浮球」）。
2. 选择工作空间与项目（可多选）→ 填写标题、描述、优先级、进度、交付物、镜像、环境变量参数（必填）、截止日期等。
3. 可勾选「是否自动运行」、填写逐仓基准分支、协作人员、工作分支与合并目标分支（支持模板 / 手写）。
4. 点击「创建任务」提交；成功后表单恢复为本次打开时的状态并自动收起浮窗，页面右下角 toast 提示成功；失败时结果仍显示在浮窗底部。

## 指针选择页面元素

1. 在描述旁点击「🖱️ 指针选择」进入选元素模式（十字光标）；Esc 或再次点击可取消。
2. **普通点击**：选中单个元素 → 填写调整期望 → 确认后追加到任务描述。
3. **多选不关联元素**：`⌘/Ctrl+点击` 累加（再点取消）→ Enter 确认；Esc 先清空多选，再按退出。多选仅限同一 frame。
4. 支持 Shadow DOM（选择器含 `>>>`）、同源/跨域 iframe、原生控件 UA Shadow（内部不可穿透时选中宿主）。
5. 可选「附带元素截图」：裁剪后上传，描述写入 https URL（多选时截取全部选中元素包围盒并集）。

## DevTools — 单请求创建任务

1. 按 F12 →「TaskPlugin」→「单请求创建」。
2. 确保 Network 面板已打开并产生请求；在本面板请求列表中搜索/筛选后点选一条。
3. 选择工作空间、项目、进度列、优先级、负责人 → 填写分支策略与任务信息 →「创建任务」。
4. 描述可用「指针选择」从页面追加元素调整块；环境变量参数为必填。
5. 优先级：高(0) / 中(1) / 低(2)。支持 Canceled（客户端中止）请求。

## DevTools — 批量错误捕获

1. 「批量错误捕获」→ 启用自动捕获，勾选状态码（含 Canceled）。
2. 角标示数 / 错误列表 / 批量建任务**仅计 HTTP 5xx**（其它码可预览但不计入示数）。
3. 选择批量创建目标 →「批量创建任务」。
4. 「错误列表」「历史记录」可查看已捕获错误与创建历史。

## 扩展弹窗 — 其它开关

1. 登录后可开关「显示悬浮球」「跟踪请求（保留刷新前的记录）」。
2. 请求预览可展开查看近期捕获；详细建任务请用 DevTools TaskPlugin 或页内浮窗。

## ⌨️ 快捷键

1. **Ctrl+Shift+X**（Mac: ⌘+Shift+X）：切换指针选择模式，在任意页面选取元素加入任务描述。
2. **F12**：打开 Chrome DevTools → 切换到 TaskPlugin 面板创建任务或批量捕获错误。
3. **Esc**：取消指针选择；多选状态下先清空多选，再按退出指针模式；关闭调整弹窗。
4. **⌘/Ctrl + 点击**：指针选择模式下累加多选不关联元素（再点取消），仅限同一 frame。
5. **Enter**：指针选择模式下确认多选，打开调整弹窗填写期望。
